\# Python untuk Pemula



Repositori latihan pembelajaran Python dasar mengikuti materi Santrikoding dengan \*virtual environment\* (`venv`), dokumentasi \*screenshot\* output, dan riwayat \*commit\* Git.



\## Materi yang Dipelajari

\- \*\*Variabel \& Tipe Data\*\*: `variable\_numbers.py`, `variable\_string.py`, `variable\_boolean.py`

\- \*\*Operator Dasar\*\*: `operator\_dasar.py`

\- \*\*Percabangan (`if`/`elif`/`else`)\*\*: `percabangan.py`

\- \*\*Perulangan (`for`/`while`)\*\*: `perulangan.py`

\- \*\*Struktur Data (`list`, `tuple`, `dictionary`)\*\*: `struktur\_data.py`

\- \*\*Fungsi (`def`, `return`)\*\*: `fungsi.py`
